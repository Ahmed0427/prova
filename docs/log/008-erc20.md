# 008: ERC-20 runs natively

## 1. What and why

The phase 1 goal: a real ERC-20 running as native RISC-V in SP1.
`contracts/erc20.sol` is a plain EIP-20 token (constant name/symbol/decimals,
`totalSupply`, `balanceOf`, `allowance`, `transfer`, `approve`,
`transferFrom` with the infinite-allowance convention, `Transfer`/`Approval`
events, `require` messages). It compiles unchanged with solc 0.8.36, which
phase 3 needs. No compiler or guest change was needed beyond 003-007.
`tests/erc20.test` covers deploy, transfers, balances, events, storage
slots, and the reverts (too little balance, too little allowance, zero
address, value sent).

## 2. Decision

**(a) Constant name and symbol.** `string public constant` instead of
storage strings set in a constructor (OpenZeppelin style): storage strings
aren't implemented (007, (e)), and a constant is common in minimal tokens.
The ABI of `name()`/`symbol()` is the same either way.

**(b) `require` messages, not custom errors.** Both work (custom errors go
through the same selector path, 007 (b)); messages match the classic
ERC-20 and exercise dynamic `Error(string)` encoding.

**(c) Test expectation `error "message"`** (host only): shorthand for
`reverts` + `output 0x08c379a0 ‖ abi.encode("message")`, so the test reads
like the contract.

## 3. How it works

Nothing new at run time; what one `transfer` does through the interface:

```
solang_call(a9059cbb ‖ to ‖ value)
  __sys_callvalue -> 0                       (not payable)
  __sys_caller    -> from
  __sys_keccak256(pad(from) ‖ 1) ; __sys_sload(balance slot)
  require(balance >= value)                  else __sys_revert(Error(...))
  __sys_sstore(from slot, balance - value)
  __sys_keccak256(pad(to) ‖ 1) ; __sys_sload ; __sys_sstore(to slot, +value)
  __sys_log(value, [keccak("Transfer(address,address,uint256)"), from, to])
  __sys_return(abi.encode(true))
```

## 4. Real code

prova, `contracts/erc20.sol` (new), the core:

```solidity
	function _transfer(address from, address to, uint256 value) internal {
		require(to != address(0), "ERC20: transfer to the zero address");
		uint256 balance = balanceOf[from];
		require(balance >= value, "ERC20: transfer amount exceeds balance");
		balanceOf[from] = balance - value;
		balanceOf[to] += value;
		emit Transfer(from, to, value);
	}
```

prova, `host/src/script.rs`: the `error` expectation.

```diff
+            // `error "message"`: reverts with Error(string).
+            "error" => {
+                let values = crate::abi::parse_values(words).map_err(at)?;
+                let mut output = vec![0x08, 0xc3, 0x79, 0xa0];
+                output.extend_from_slice(&crate::abi::encode(&values));
+                case.reverts = true;
+                case.expect.push(Expect::Output(output));
+            }
```
